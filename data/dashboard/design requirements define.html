토큰 정의 + 컴포넌트 스펙 · dataviz 스킬 레퍼런스 팔레트 기준 · v1 (2026-07-12)

1. 색상 토큰 --good / --warning / --serious / --critical 등

기존 dashboard_template.html의 팔레트를 그대로 쓰되, status 4종(good/warning/serious/ critical)은 라이트·다크에서 같은 헥스값으로 고정했다 — dataviz 레퍼런스의 규칙("fixed — never themed")이며, 밸리데이터로 4색 상호 대비(CVD ΔE 최솟값 16.4, 목표 12 통과)와 다크 서피스 대비(전부 ≥3:1)를 확인함. warning·serious는 라이트 서피스에서 3:1 미만이라 아이콘+레이블 병기가 필수이며 배지 컴포넌트에서 실제로 그렇게 쓴다.

✓ CVD 분리 통과 (ΔE 16.4 ≥ 12) · ⚠ warning/serious 라이트 대비 <3:1 → 색만으로 의미 전달 금지, 항상 아이콘+텍스트 병기

2. 타이포그래피

시스템 산세리프 고정(system-ui, -apple-system, "Segoe UI", sans-serif) — 디스플레이/세리프 서체 없음. 큰 단독 숫자(타일 값)는 비례폭 숫자, 테이블/축처럼 정렬이 필요한 컬럼만 tabular-nums.

4. 바 리스트 · 랭킹 테이블 기존 컴포넌트

단일 계열이라 범례 불필요(제목이 곧 범례). 막대는 accent 1색, 트랙은 --track. 테이블의 서브 지표(V/M/Q/G)는 마이크로트랙 + 값 — 개별 라벨 없이 헤더가 담당.

5. 결정 배지 (신규) BUY / HOLD / SELL × 확신도

결정(BUY/SELL)만 status hue(good/critical) 사용. HOLD는 5번째 상태색을 새로 만들지 않고 중립 텍스트 토큰(--ink-2)으로 표현 — "상태색은 재사용 금지, 중립은 색이 아니라 무채색" 원칙. 확신도는 색을 바꾸지 않고 동일 색상의 채움 점(dot meter)으로 표현(미터 컴포넌트와 동일 규칙: 채움이 심각도를 나타내고 트랙은 같은 램프의 옅은 단계). 아이콘+레이블은 항상 함께 — 색만으로 의미 전달 금지.

6. 탭 (신규) 스캔 / 결과 / History / 로그

언더라인 인디케이터, 활성 색은 --accent 1가지만(다른 의미 부여 금지). 카운트는 mono 보조 텍스트.

7. 결과 탭 레이아웃 (신규) 리포트 + History 패널

본문(리포트) + 우측 고정폭 History 리스트. 선택된 세션은 좌측 accent 룰(3px)로 표시 — 배경 워시가 아니라 룰 하나로, 배지 색과 충돌하지 않게.

선택된 세션 리포트 결과 탭은 선택한 세션의 마크다운 리포트 전문을 렌더링하는 영역이다. 좌측 본문 폭은 가독성을 위해 72ch 내외로 제한한다.

8. 로그 / 트랜스크립트 타임라인 (신규) 로그 탭

세로 레일(hairline) + 이벤트 점. 점 색은 종류 구분용 상태값(accent=도구 호출, muted=텍스트, critical=오류)이며 항상 라벨과 함께.
